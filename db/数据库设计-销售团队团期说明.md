# 销售团队团期表说明

本文件说明 `012_sales_team_schema.sql` 中的销售团期与团队价格表。团期管理不是产品模板上的日期字段，而是从产品生成正式团队记录；同一团队可以按客户类型维护多套价格。

## 设计原则

- 产品模板负责线路基础资料，团期管理负责生成可收客的正式团队。
- 团期管理默认生成 `sanpin` 散拼团队，后续整团、散团、单项共用团队主表扩展。
- 团队主数据和客户类型价格分表保存，避免同一团有多套客户价格时重复保存团队字段。
- 团队状态、团队类型、价格状态通过 `CHECK` 约束限定允许值。
- 团队和价格默认软删除，普通删除不物理移除记录。
- 团号生成需要记录日志，便于后续排查同日多团后缀。

## 表清单

| 表名 | 作用 |
| --- | --- |
| `sales_teams` | 销售团队主表，保存团号、团队类型、业务类型、归属部门、操作计调、全陪、发团日期、状态、总位、余位、单房差、内部备注测算值等团队级信息。 |
| `sales_team_prices` | 销售团队价格表，保存同一团队不同客户类型下的成人、儿童、儿童不占床、老人和附加费价格。 |
| `sales_team_status_logs` | 团队状态日志表，记录创建、停收、恢复、取消和删除动作。 |
| `sales_team_no_logs` | 团号生成日志表，记录生成团号时使用的日期、后缀和最终团号。 |

## 关键字段

### `sales_teams`

| 字段 | 说明 |
| --- | --- |
| `product_id` | 所属销售产品模板 ID。 |
| `team_no` | 团队编号。当前按产品简称、散拼标记、发团日期和后缀生成。 |
| `team_type` | 团队类型：`sanpin` 散拼，`zhengtuan` 整团，`santuan` 散团，`single` 单项。团期管理默认 `sanpin`。 |
| `business_type` | 团队业务类型快照，默认从产品业务类型或产品团队安排资料带入，正式团队可单独修改。 |
| `departure_date` | 发团日期。 |
| `department_id` / `department_name` | 团队归属部门 ID 和名称快照。 |
| `operator_employee_id` / `operator_employee_name` | 操作计调员工 ID 和姓名快照。 |
| `escort_employee_id` / `escort_employee_name` | 全陪员工 ID 和姓名快照。 |
| `status` | `normal` 正常，`stopped` 停收，`cancelled` 取消。 |
| `total_seats` | 总位数。 |
| `used_seats` | 已收客或已占用位数。 |
| `remaining_seats` | 剩余位数。批量生成时默认等于总位数。 |
| `single_room_difference` | 单人房差价格。 |
| `close_days_before` | 出团前截止收客天数，从产品默认值带入。 |
| `per_capita_pit_amount` | 团队人均坑位金额，用于内部备注和导游备用金测算参考。 |
| `optional_markup_rate` | 团队自费加点率，按百分数保存，例如 `70` 表示 `70%`；导游备用金计算未手工指定本次公司加点率时，优先作为本团默认锚点。 |
| `per_capita_shopping_amount` | 团队人均购物金额，用于内部备注和购物预期测算参考。 |

### `sales_team_prices`

| 字段 | 说明 |
| --- | --- |
| `team_id` | 所属销售团队 ID。 |
| `product_id` | 所属销售产品模板 ID，用于按产品团期快速查询。 |
| `customer_category_id` / `customer_category_name` | 客户类型 ID 和名称快照；为空时表示默认客户类型。 |
| `adult_price` | 成人价格。 |
| `child_price` | 儿童价格。 |
| `child_no_bed_price` | 儿童不占床价格。 |
| `senior_price` | 老人价格。 |
| `extra_fee` | 附加费用。 |
| `status` | `active` 启用，`disabled` 停用。 |

### `sales_team_status_logs`

| 字段 | 说明 |
| --- | --- |
| `team_id` | 所属销售团队 ID。 |
| `from_status` / `to_status` | 变更前和变更后状态。 |
| `action_type` | 状态动作：创建、停收、启用、取消、恢复、删除。 |
| `operator` | 操作人账号或名称。 |
| `action_time` | 操作时间。 |

### `sales_team_no_logs`

| 字段 | 说明 |
| --- | --- |
| `product_id` | 所属销售产品模板 ID。 |
| `departure_date` | 发团日期。 |
| `team_no` | 生成的团队编号。 |
| `suffix_code` | 团号后缀，例如 `A`、`B`、`Z0`。 |

## 状态规则

| 操作 | 允许状态 | 结果 |
| --- | --- | --- |
| 批量新增团期 | 产品启用 | 生成正常状态散拼团队和默认价格行，并把产品团队安排资料复制为团队快照。 |
| 停收 | `normal` | 团队状态改为 `stopped`。 |
| 启用 | `stopped` | 团队状态改为 `normal`。 |
| 取消 | `normal` / `stopped` | 团队状态改为 `cancelled`。 |
| 恢复 | `cancelled` | 团队状态改为 `normal`。 |
| 删除团队 | `cancelled` | 软删除团队和价格行。 |
| 删除价格行 | 任意未删除价格行 | 只软删除价格行，不删除团队。 |

## 模块边界

- 本模块只实现产品下的团期管理页、团队主记录和客户类型价格维护。
- 团队详情、正式订单收客、拼团、转团、导游报账、计调履约和财务结算不在本表说明范围内。
- 余位后续应由订单收客、退团和转团等动作维护；当前批量生成时仅按总位初始化。
- 团期列表需要按产品、日期、状态、操作计调分页查询，不能无条件返回全部团队。
