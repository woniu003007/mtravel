# 数据库设计：购物业绩与公司补佣

## 模块边界

购物业绩与公司补佣是独立的内部核算链路，不直接等同于普通订单收入，也不直接等同于银行收款。

- 团队安排中的购物安排仍保存在 `dispatch_team_arrangements`，用于排团计划、预估消费和预算利润参考。
- 真实购物反馈、品类核对和公司补佣不放在团队安排页录入，第一版入口放在团队操作页和财务团队审核页的单团 `购物核对/补佣` 弹窗；不单独暴露“购物业绩”业务菜单。
- 购物店实际反馈汇总保存在 `finance_shopping_feedback_lines`，同一购物店下的品类消费详情保存在 `finance_shopping_feedback_detail_lines`，作为购物佣金计算和导游报账核对依据。
- 购物阶梯规则保存在 `finance_shopping_commission_rules`，团队特殊比例保存在 `finance_shopping_team_rule_overrides`，只用于参考测算是否达标和参考补差。
- 每次重新计算生成 `finance_shopping_settlements` 和 `finance_shopping_settlement_lines` 快照，旧快照不覆盖。
- 导游从购物店现场取得的佣金只做业务核对，不作为公司成本扣减。
- 计调确认由公司补给导游的金额保存在 `finance_shopping_settlements.manual_guide_bonus_amount`，作为正式内账扣减金额。
- 购物相关无发票金额进入内账核算，不默认进入外账税务口径。

## 核心业务规则

- 综合人均消费默认按团队实收人数计算，不按进店人数计算。
- 默认规则为：人均消费门槛 5000 元，基础导游佣金 8%，达标目标佣金 10%。
- 达标后参考补差采用全额补差：`参考补差 = 全团购物消费总额 × (目标佣金比例 - 基础佣金比例)`。
- 参考补差不自动生成正式成本，也不自动写入团队账单；计调需根据单团账单确认实际公司补佣金额。
- 计调可以按团队覆盖门槛和比例，覆盖记录必须保留原因、操作人和时间。
- 购物店反馈支持单条录入，后续可扩展 Excel 导入批次；修改单条反馈不能重建整组购物数据。
- 同一家购物店可按品类拆分消费详情。例如茶叶和茶多酚属于同一家店但返点不一致时，父记录只保存购物店和汇总金额，子明细按品类分别保存消费金额、公司返点、导游现场提成和现结核对金额。
- `总额返佣` 和 `按品类返佣` 不走两套计算逻辑；总额返佣会生成一条“综合”消费详情，按品类返佣会生成多条品类消费详情，父表金额均由消费详情汇总。
- 重新计算时生成新的结算快照，之前有效快照标记为 `superseded`。

## 计算公式

团队人均购物消费：

```text
人均购物消费 = 全团购物消费总额 / 团队实收人数
```

参考阶梯补差：

```text
未达标：0
达标：全团购物消费总额 × (达标目标佣金比例 - 基础佣金比例)
```

内部公司购物利润：

```text
内部公司购物利润 = 人头费合计 + 公司返佣合计 - 公司补佣金额
```

当前外账口径：

```text
外账公司购物利润 = 0
```

原因：导游现场佣金多数由导游从购物店直接取得，不经过公司公账；公司补佣属于内部核算口径，不默认进入外账税务申报。后续如果出现公司公账收取购物返佣，应通过购物返佣应收和收款分摊单独入账。

## 表说明

### `finance_shopping_commission_rules`

购物参考阶梯规则默认表。维护公司层面的综合人均消费门槛、基础比例和达标比例，用于补佣参考测算。

| 字段 | 中文含义 |
| --- | --- |
| `rule_name` | 规则名称。 |
| `threshold_per_capita_amount` | 人均消费门槛金额。 |
| `base_commission_rate` | 基础导游佣金比例，按百分数保存。 |
| `target_commission_rate` | 达标后目标导游佣金比例，按百分数保存。 |
| `ladder_calc_mode` | 阶梯补差方式。当前为 `full_amount_diff`，表示达标后按全团消费全额补差。 |
| `effective_start_date` | 生效开始日期。 |
| `effective_end_date` | 生效结束日期。 |
| `status` | 规则状态。 |

### `finance_shopping_team_rule_overrides`

团队购物参考阶梯规则覆盖表。保存计调按团队调整门槛和比例的快照。

| 字段 | 中文含义 |
| --- | --- |
| `team_id` / `team_no` | 团队 ID 和团号快照。 |
| `threshold_per_capita_amount` | 团队覆盖后的人均消费门槛金额。 |
| `base_commission_rate` | 团队覆盖后的基础导游佣金比例。 |
| `target_commission_rate` | 团队覆盖后的达标目标佣金比例。 |
| `ladder_calc_mode` | 团队覆盖后的阶梯补差方式。 |
| `override_reason` | 团队规则覆盖原因。 |
| `overridden_by` / `overridden_at` | 覆盖操作人和时间。 |
| `status` | 覆盖状态。`active` 生效，`superseded` 被新规则替代，`cancelled` 作废。 |

### `finance_shopping_feedback_lines`

购物店业绩反馈汇总表。保存单个购物店反馈的购物店、导游、日期、进店人数和汇总金额；正式计算以消费详情汇总后的结果为准。

| 字段 | 中文含义 |
| --- | --- |
| `team_id` / `team_no` | 团队 ID 和团号快照。 |
| `supplier_id` / `shop_name` | 购物店供应商 ID 和购物店名称。 |
| `guide_id` / `guide_name` | 导游 ID 和姓名快照。 |
| `business_date` | 消费或反馈业务日期。 |
| `people_count` | 进店人数。 |
| `consumption_amount` | 消费总额。 |
| `company_rebate_amount` | 公司返佣金额。 |
| `guide_commission_amount` | 导游从购物店现场取得或应得的佣金金额，仅用于业务核对。 |
| `head_fee_amount` | 人头费金额。 |
| `rebate_calc_mode` | 返佣计算模式。`total` 总额返佣，`category` 按品类返佣。 |
| `feedback_source` | 反馈来源。`manual` 人工，`excel` 导入，`api` 接口。 |
| `import_batch_id` | Excel 导入批次 ID。 |
| `status` | 反馈状态。 |

### `finance_shopping_feedback_detail_lines`

购物反馈消费详情表。保存总额返佣的“综合”明细，或按品类返佣的多行消费详情。后续导游报账购物核对应优先按该表的品类明细展示。

| 字段 | 中文含义 |
| --- | --- |
| `feedback_line_id` | 购物反馈汇总记录 ID。 |
| `team_id` | 团队 ID，冗余保存便于团队页批量查询。 |
| `category_name` | 购物品类。总额返佣模式固定为“综合”。 |
| `people_count` | 当前品类进店人数，用于核对，不作为团队人均消费分母。 |
| `head_fee_amount` | 人头费金额。 |
| `consumption_amount` | 消费金额。 |
| `company_rebate_rate` | 公司返佣比例，按百分数保存。 |
| `company_rebate_amount` | 公司返佣金额。 |
| `guide_commission_rate` | 导游现场提成比例，按百分数保存。 |
| `guide_commission_amount` | 导游现场提成金额，仅用于业务核对。 |
| `cash_amount` | 购物店现场现结金额，仅用于核对。 |
| `sort_order` | 排序号。 |

### `finance_shopping_settlements`

购物业绩结算快照表。保存团队购物消费汇总、参考补差、公司补佣和内外账公司利润。

| 字段 | 中文含义 |
| --- | --- |
| `team_id` / `team_no` | 团队 ID 和团号快照。 |
| `team_type` / `business_type` / `departure_date` | 团队类型、业务类型和发团日期快照。 |
| `rule_source` | 规则来源。`system_default` 系统默认，`default_rule` 公司默认规则，`team_override` 团队覆盖。 |
| `guest_count` | 团队实收人数。 |
| `threshold_per_capita_amount` | 计算时的人均消费门槛。 |
| `base_commission_rate` | 计算时的基础导游佣金比例。 |
| `target_commission_rate` | 计算时的达标目标佣金比例。 |
| `total_consumption_amount` | 全团购物消费总额。 |
| `per_capita_consumption_amount` | 按团队实收人数计算的人均购物消费。 |
| `threshold_reached` | 是否达到参考阶梯门槛。 |
| `base_guide_commission_amount` | 按基础比例测算的参考导游佣金金额。 |
| `ladder_extra_commission_amount` | 达标后的参考阶梯补差佣金，不自动计入正式成本。 |
| `guide_commission_total_amount` | 导游现场佣金加参考补差的展示合计，不自动计入公司成本。 |
| `manual_guide_bonus_amount` | 计调确认由公司补给导游的正式补佣金额，参与内部购物利润扣减。 |
| `manual_guide_bonus_remark` | 公司补佣说明。 |
| `company_rebate_amount` | 公司返佣合计。 |
| `head_fee_amount` | 人头费合计。 |
| `internal_company_profit_amount` | 内账公司购物利润，可用于真实毛利。 |
| `external_company_profit_amount` | 外账公司购物利润，无发票购物佣金默认不进入外账。 |
| `calculated_by` / `calculated_at` | 计算人和计算时间。 |
| `status` | 结算状态。`active` 当前有效，`superseded` 被新计算替代，`cancelled` 作废。 |

### `finance_shopping_settlement_lines`

购物佣金结算明细表。按购物店反馈行保存结算快照明细。

| 字段 | 中文含义 |
| --- | --- |
| `settlement_id` | 购物佣金结算快照 ID。 |
| `feedback_line_id` | 购物反馈明细 ID。 |
| `supplier_id` / `shop_name` | 购物店供应商 ID 和购物店名称。 |
| `business_date` | 消费日期。 |
| `people_count` | 进店人数。 |
| `consumption_amount` | 消费总额。 |
| `company_rebate_amount` | 公司返佣金额。 |
| `guide_commission_amount` | 导游从购物店现场取得或应得的佣金金额，仅用于业务核对。 |
| `head_fee_amount` | 人头费金额。 |
| `line_company_profit_amount` | 明细行公司购物利润，按人头费加公司返佣计算，不扣导游现场佣金。 |
| `sort_order` | 排序号。 |

## 统计和财务影响

- 团队预算利润应使用 `finance_shopping_settlements.internal_company_profit_amount` 作为实际购物利润优先口径；无结算快照时才回退到团队安排购物预估。
- 导游统计可按 `guide_id`、`team_id`、`departure_date` 汇总购物消费、导游现场佣金和公司补佣；导游报账核对需要下钻到 `finance_shopping_feedback_detail_lines.category_name`，避免同店不同品类返点混在一起。
- 购物返佣应收、购物收款和银行现金账后续仍需独立表记录真实收款，不应把结算快照当作银行流水。
- 财务外账默认不读取无发票购物佣金；内账经营统计读取内部利润。

## 索引设计

- 反馈汇总按租户、团队、状态、业务日期建立索引，支撑团队页和导游报账核对。
- 反馈汇总按租户、供应商、业务日期建立索引，支撑购物店维度统计。
- 反馈汇总按租户、导游、业务日期建立索引，支撑导游统计。
- 消费详情按租户、反馈汇总记录和排序建立索引，支撑打开购物反馈时批量加载品类明细。
- 消费详情按租户、团队和品类建立索引，支撑同团品类维度核对和后续品类返佣统计。
- 结算快照按租户、团队、状态和计算时间建立索引，保证团队页快速读取最新结果。
- 结算快照按租户、发团日期和状态建立索引，支撑财务统计。
