# 数据库设计：导游备用金

## 模块边界

导游备用金是独立资金链路，不直接等同于团队成本，也不等同于银行现金流水。

- 团队安排成本来源仍在 `dispatch_team_arrangements`。
- 导游备用金申请、总经理审批和付款汇总保存在 `finance_guide_imprests`。
- 每次申请的计算依据保存在 `finance_guide_imprest_calc_lines`，用于后续查账。
- 一张申请可以分多次付款，付款记录保存在 `finance_guide_imprest_payments`。
- 后续导游报账、导游结算、银行现金账可以引用备用金申请或付款记录，但不能覆盖备用金历史申请快照。

## 业务规则

- 只有团队安排中的 `cash_amount` 现付金额占用导游备用金；`credit_amount` 挂账由公司和供应商结算，不占用导游备用金。
- 同一团队同一导游允许多次申请备用金。每次申请代表一次新的授权，必须单独提交、单独审批。
- 建议余额参考 = 当前建议备用金 - 同团队同导游已申请/已批金额。该值只作为风险提示，不作为本次申请硬上限。
- `suggested_imprest_amount` 是系统计算出来的建议备用金，只作为计调申请参考，不等同于真实申请金额。
- `requested_amount` 是计调本次手工填写并提交审批的真实申请金额，可以因现场临时现付、特殊项目或应急需要超过系统建议金额；申请后累计金额超过系统建议金额时，必须填写应急或特殊项目说明。
- 公司加点率默认优先读取团队内部备注中的 `optional_markup_rate` 自费加点率；团队未设置或为 `0` 时读取系统配置。计调可在每次申请时按本团、本导游实际情况调整；提交后保存为本次申请快照，后续审批和付款校验使用快照值，不被团队备注或全局配置变化覆盖。
- 申请提交后保存团队、导游、实收人数、现付成本、自费抵扣和计算明细快照。后续团队安排变更不能自动覆盖历史申请。
- 审批或付款前必须用当前团队安排重新计算。若当前计算与申请快照不一致，禁止审批通过和付款，要求作废旧申请后重新计算提交。
- 未付款的待审批或已审批申请可以作废。作废不删除申请、计算明细和审批历史，只从后续风险提示汇总中排除。
- 已付款申请不能直接作废，后续应通过导游结算、退款或冲销流水处理。
- 一张已审批申请可以分多次付款，但累计付款金额不能超过审批金额。
- 团队安排导游行展示的“累计已批备用金”按 `approved_amount` 汇总，只统计已审批、已付款、已结算的有效申请；待总经理审批金额单独汇总展示，不计入累计已批。

## 计算公式

建议备用金：

```text
建议备用金 = 现付总成本 - 自费加点抵扣金额
```

自费加点抵扣金额：

```text
Σ[(自费售价 - 自费成本 - 导游成本) × 公司规定加点率] × 团队实收人数
```

导游成本计算：

- 固定金额：取 `guide_commission_amount`，单位元/人。
- 百分比：取 `(sale_price - cost_price) × guide_commission_rate / 100`。

当公式结果小于 0：

- `suggested_imprest_amount` 记为 0。
- `guide_turn_in_amount` 记为公式结果绝对值。
- `calculated_amount` 保留原始负数，方便解释为什么不需要发放备用金。

当前阶段处理口径：

- 备用金不能为负数。公式结果为负数时，只表示本团不需要向导游发放备用金，并产生导游应上交公司的金额。
- `guide_turn_in_amount` 是导游应上交公司金额，不是备用金，不是团队成本，也不写入下次团队备用金公式。
- 当前阶段只保存备用金申请和计算快照，不生成导游欠款余额、导游往来账、核销流水，也不自动带入下次带团抵扣。
- 下次同一导游带团时，备用金仍按新团队自己的现付成本和自费抵扣重新计算。
- 后续开发导游结算或导游往来账时，`guide_turn_in_amount` 可作为待核销来源进入导游应上交记录；是否从下次备用金付款中抵扣，应由财务在付款环节人工选择。
- 财务选择抵扣时，必须生成明确的抵扣核销记录，记录来源申请、抵扣金额、实际付款金额和剩余未结算金额。禁止无核销流水直接少付款。

公司规定加点率默认来源：

1. 计调在本次备用金弹窗手工填写的公司加点率。
2. 团队内部备注字段 `sales_teams.optional_markup_rate`，且值大于 `0`。
3. 系统配置 `guide_imprest_company_markup_rate`。

系统配置键：

| 配置键 | 默认值 | 含义 |
| --- | --- | --- |
| `guide_imprest_company_markup_rate` | `70` | 导游备用金抵扣公式中的公司规定加点率，按百分数保存。 |

## 表说明

### `finance_guide_imprests`

导游备用金申请主表。保存团队、导游、计调、实收人数、计算汇总、申请金额、审批状态和付款汇总。

关键字段：

| 字段 | 中文含义 |
| --- | --- |
| `request_no` | 备用金申请编号。 |
| `team_id` / `team_no` | 关联团队和团号快照。 |
| `guide_id` / `guide_name` / `guide_mobile` | 导游快照。 |
| `guest_count` | 团队实收人数快照。 |
| `company_markup_rate` | 本次公司加点率快照，默认取系统配置，也允许按申请覆盖。 |
| `cash_cost_amount` | 计算时现付总成本。 |
| `optional_deduction_amount` | 自费加点抵扣金额。 |
| `calculated_amount` | 原始公式计算结果，可为负数。 |
| `suggested_imprest_amount` | 建议发放备用金。 |
| `guide_turn_in_amount` | 公式为负数时导游应上交金额。 |
| `requested_amount` | 计调本次手工填写的申请发放金额。 |
| `approved_amount` | 总经理同意后的审批金额。 |
| `paid_amount` | 已付款金额汇总。 |
| `balance_amount` | 剩余未付款金额。 |
| `cancelled_by` | 作废人账号或姓名。 |
| `cancelled_at` | 作废时间。 |
| `cancel_reason` | 作废原因。 |
| `status` | 申请状态。 |

状态值：

| 状态 | 中文含义 |
| --- | --- |
| `draft` | 草稿。 |
| `pending_manager` | 待总经理审批。 |
| `manager_approved` | 总经理已同意，允许财务付款。 |
| `manager_rejected` | 总经理已拒绝。 |
| `paid` | 已完成本申请付款。 |
| `settled` | 已进入导游结算并完成核销。 |
| `cancelled` | 已取消。 |

### `finance_guide_imprest_calc_lines`

导游备用金计算明细表。保存每次申请时的计算依据。

| 字段 | 中文含义 |
| --- | --- |
| `line_type` | 明细类型。`cash_cost` 现付成本，`optional_deduction` 自费加点抵扣。 |
| `source_arrangement_id` | 来源团队安排成本 ID。 |
| `source_price_line_id` | 来源价格明细 ID。 |
| `arrangement_type` | 团队安排类型。 |
| `item_name` | 项目名称。 |
| `sale_price` | 自费售价快照。 |
| `cost_price` | 自费成本快照。 |
| `guide_commission_amount` | 导游提成金额快照。 |
| `guide_commission_rate` | 导游提成比例快照。 |
| `guide_commission_calc_type` | 导游提成计算方式。 |
| `company_markup_rate` | 本次公司加点率快照。 |
| `guest_count` | 团队实收人数快照。 |
| `amount` | 本行计算金额。 |

### `finance_guide_imprest_payments`

导游备用金付款记录表。一张备用金申请可以分多次付款。

| 字段 | 中文含义 |
| --- | --- |
| `payment_no` | 付款编号。 |
| `payment_date` | 付款日期。 |
| `payment_method` | 付款方式。 |
| `payment_account_name` | 付款账户名称。 |
| `amount` | 本次付款金额。 |
| `payer` | 付款经办人。 |
| `status` | 付款记录状态。 |

## 索引设计

- `finance_guide_imprests` 按租户、状态、团队、导游、发团日期、计调和创建时间建立索引。
- `finance_guide_imprest_calc_lines` 按备用金申请和团队建立索引。
- `finance_guide_imprest_payments` 按备用金申请、团队和付款日期建立索引。

这些索引用于支撑导游备用金列表、总经理审批列表、团队详情追溯和后续财务统计。
