# 销售产品设计工作台表说明

本文件说明 `037_sales_product_designer_schema.sql`、`038_sales_product_design_draft_scope.sql` 及 `040_sales_product_day_resource_introductions.sql` 的产品设计工作台相关结构。产品设计工作台使用 `sales_products.product_scope='design_draft'` 保存尚未进入产品管理的设计草稿，按天选择资源、组合多个介绍素材并保存顺序快照、计算成人报价，并在完成设计后切换为正式产品模板，为后续产品 Word 和成人报价单生成提供稳定数据来源。

## 设计原则

- 工作台按单条资源保存，不复用产品模板完整保存接口，避免拖拽和排序时重建整组行程。
- 设计草稿和正式产品模板共用 `sales_products` 主表，但必须通过 `product_scope` 隔离列表和生命周期；草稿完成设计后切换为 `template` 才进入产品管理。
- `sales_products` 的名称唯一索引只覆盖同租户未删除的 `template` 与 `design_draft`，既防止草稿并发重名，也防止草稿转正式时与已有正式产品同名；团队专属快照 `team_snapshot` 不参与该约束。
- 产品侧保存资源名称、坐标、供应商、成本和介绍正文快照，资源主档后续修改不能反向改变已生成的产品文件。
- 免费资源使用 `procurement_mode_snapshot='not_required'`，成本为 0，且不强制供应商。
- 供应商和分类报价仍来自 `purchase_relations`、`supplier_resource_prices`，产品工作台不维护另一套供应商报价。
- 自费项目只在产品设计台单独保存快照，最终对外价由产品设计台填写，Word 只输出最终对外价，不输出供应商成本价或建议对外价。
- 自费项目不计入成人成本和成人报价口径；成人成本只统计正常行程资源的成本快照。
- 成人报价由后端根据当前产品资源成本快照计算成人成本，前端不能作为最终金额权威。
- 生成文件版本表保存不可变生成记录，后续 Word 和报价单下载以版本为准。

## 表清单

| 表名 | 作用 |
| --- | --- |
| `sales_product_day_resources` | 产品某一天选用的采购资源、排序、停留时长、供应商、成本和介绍正文快照。 |
| `sales_product_day_resource_introductions` | 一个产品日资源选择的多个介绍素材快照及其 Word 输出顺序。 |
| `sales_product_day_resource_optional_items` | 产品每日资源选择的多个自费项目快照、供应商成本快照、建议价快照、最终对外价和介绍快照。 |
| `sales_product_day_resource_images` | 产品生成 Word 时选用的资源图片快照。 |
| `sales_product_adult_quotes` | 产品成人报价草稿，保存计划成人数、成人成本、加价和成人对外价。 |
| `sales_product_document_versions` | 产品 Word 和成人报价单的生成版本记录。 |

## 关键关系

```text
sales_products
└── sales_product_day_resources
    ├── purchase_resources
    ├── suppliers
    ├── purchase_resource_introductions
    ├── sales_product_day_resource_introductions
    ├── sales_product_day_resource_optional_items
    └── sales_product_day_resource_images
        └── purchase_resource_images / common_attachments

sales_products
├── sales_product_adult_quotes
└── sales_product_document_versions
```

`038_sales_product_design_draft_scope.sql` 负责补齐 `sales_products.product_scope` 的 `design_draft` 约束、按用途分页查询索引，以及 `template/design_draft` 统一产品名称唯一索引。若目标库已执行过旧版 `026_sales_product_scope.sql`，仍需执行 038 以收敛约束和索引定义。

## 关键字段

### `sales_product_day_resources`

| 字段 | 说明 |
| --- | --- |
| `product_id` | 销售产品 ID。设计阶段指向 `product_scope='design_draft'` 的草稿，完成设计后同一产品切换为 `template`。 |
| `day_no` | 产品行程第几天，从 1 开始。 |
| `resource_id` | 采购资源主档 ID。 |
| `arrangement_role` | 资源在当天的业务归属：酒店固定为 `accommodation`；餐厅为 `breakfast`、`lunch`、`dinner` 或历史兼容的 `unassigned`；其它资源为 `itinerary`。同一天可安排多个酒店，每个餐次仅一个餐厅。 |
| `hotel_breakfast_included` | 当晚酒店是否包含次日早餐；仅住宿酒店可设置。若次日已安排早餐餐厅，则不允许再标记酒店含早。 |
| `resource_*_snapshot` | 资源名称、类型、地区、地址和坐标快照。 |
| `procurement_mode_snapshot` | 采购属性快照。`required` 需要采购，`not_required` 无需采购。 |
| `sort_order` | 当天资源顺序。 |
| `stay_minutes` | 计划停留时长。 |
| `include_in_word` | 是否进入产品 Word 输出。 |
| `supplier_id` / `supplier_name_snapshot` | 选中的供应商和名称快照。无需采购资源为空。 |
| `unit_price_snapshot` / `quantity_snapshot` / `cost_amount_snapshot` | 后端计算的单位成本、数量和成本小计快照。 |
| `selected_introduction_id` | 选中的已发布资源介绍 ID。 |
| `introduction_*_snapshot` | 介绍版本号、标题、正文、温馨提示、注意事项和游览时间快照，用于 Word 生成；注意事项按非空行逐条红色输出，温馨提示按普通文字输出。 |

### `sales_product_day_resource_introductions`

| 字段 | 说明 |
| --- | --- |
| `day_resource_id` | 产品某天的资源编排 ID。 |
| `resource_introduction_id` | 资源主档介绍素材 ID，仅用于追踪来源；生成文件以快照为准。 |
| `introduction_index_version` | 保存时介绍素材的向量索引版本快照。 |
| `title_snapshot` / `content_snapshot` | 介绍标题和正文快照；同一资源可保存多条素材。 |
| `notice_snapshot` | 介绍注意事项快照，生成 Word 时逐条红色输出。 |
| `warm_tip_snapshot` | 介绍温馨提示快照，生成 Word 时逐条普通文字输出。 |
| `extension_blocks_snapshot` | 介绍正文后的结构化扩展内容模块快照，保留拍照机位推荐、温馨提示等模块及其条目排序。 |
| `visit_duration_snapshot` | 介绍游览时间快照，生成 Word 时按素材原值输出。 |
| `sort_order` | 同一资源内的介绍组合顺序，从 1 开始。 |

产品设计请求通过 `introductionIds` 按顺序提交多个已发布介绍 ID；空列表表示清空。旧的 `selected_introduction_id` 及单条介绍快照字段继续保留，作为旧数据和旧客户端的兼容回退。生成 Word 时优先读取该子表，按 `sort_order` 串联正文；没有子表快照时回退到每日资源旧单条快照。

### `sales_product_day_resource_optional_items`

| 字段 | 说明 |
| --- | --- |
| `day_resource_id` | 产品某天的资源编排 ID。 |
| `resource_optional_item_id` | 资源级自费项目主档 ID。 |
| `supplier_optional_item_id` | 选中的供应商自费报价 ID。 |
| `item_type_snapshot` | 自费项目类型快照。 |
| `project_name_snapshot` | 自费项目名称快照。 |
| `price_unit_snapshot` | 固定元/人计价单位快照。 |
| `supplier_cost_price_snapshot` | 供应商成本价快照，仅内部使用。 |
| `suggested_sale_price_snapshot` | 供应商建议对外价快照，仅作为默认值。 |
| `final_sale_price` | 本产品最终对外自费价，Word 只读取这个值。 |
| `selected_introduction_id` | 选中的自费项目介绍素材 ID。 |
| `introduction_title_snapshot` / `introduction_content_snapshot` | 自费项目介绍标题和正文快照。 |
| `introduction_notice_snapshot` | 自费项目注意事项快照，生成 Word 时按红色提示输出。 |
| `introduction_warm_tip_snapshot` | 自费项目温馨提示快照，生成 Word 时按普通文字输出。 |
| `introduction_visit_duration_snapshot` | 自费项目游览时间快照。 |
| `sort_order` | 同一日资源下自费项目的输出顺序，从 1 开始。 |

产品设计请求通过 `selectedOptionalItems` 提交多个自费项目快照；空数组表示清空。保存时后端只接受最终对外价，供应商成本价和建议对外价必须由后端重算并快照，不能直接信任前端传值。

### `sales_product_adult_quotes`

| 字段 | 说明 |
| --- | --- |
| `planned_adult_count` | 计划成人数量。 |

### `sales_product_document_versions`

| 字段 | 说明 |
| --- | --- |
| `document_type` | `product_word` 产品介绍 Word，`adult_quote` 成人报价单。 |
| `version_no` | 同产品同文档类型下的版本号。 |
| `source_snapshot` | 生成时使用的产品、行程、资源介绍、图片和报价来源快照。 |
| `attachment_id` | 生成文件附件 ID。 |
| `generate_status` | `pending` 处理中，`success` 成功，`failed` 失败。 |

## 当前实现边界

- 工作台后端契约、单条资源编排、多个介绍素材按序快照、自费项目快照、图片快照、成人报价、产品 Word、成人报价单、文件版本查询和下载已经实现。
- 当前生命周期口径为：在销售管理的“产品设计”独立菜单中新建设计草稿，进入工作台完成资源和报价编排，完成设计后将 `product_scope` 从 `design_draft` 切换为 `template`，随后出现在产品管理。
- 文档首版采用同步生成；生成失败时保留页面重试入口，后续数据量增大再拆分异步任务。
- 2026-08-18 确认目标库已存在 037 对应的 4 张工作台表，并已事务执行 `038_sales_product_design_draft_scope.sql`。`sales_products` 的列、约束、索引和注释与本地 011 校验结果全部为 `match`，真实草稿发布与删除清理链路已通过。
