# 计调房源与房态库存表说明

本文件说明 `009_dispatch_room_status_schema.sql` 中的计调房源与房态库存结构。

## 设计定位

本模块只解决计调排房前的房源库存准备和锁房联动，不重复建设采购资源模块。

当前房源来源分两类：

- `自营房源`：企业已买断、包房或长期取得使用权的酒店房源，可以维护酒店档案、房型、价格、有效期、可选房号和每日库存。
- `资源采购房源`：来自 `采购管理 / 资源采购管理` 和 `采购关系管理` 的外部酒店采购关系，只在房态库存中维护日期、房型和数量，不维护房号。

计调排房时优先按 `酒店 + 来源 + 房型 + 日期` 查看聚合库存：`总量 / 已锁 / 已占 / 余量`。锁房先按房型数量锁定，不强制先选具体房号；自营房源后续需要精细排房时再补具体房号。

## 设计原则

- 采购管理已有的资源、供应商、采购关系和价格资料不在本模块重做。
- 所有业务表均带 `tenant_id`，后端查询和修改必须按租户隔离。
- 业务删除使用软删除字段：`is_deleted`、`deleted_at`、`deleted_by`。
- 状态字段使用 `varchar(20)`，并通过 `CHECK` 约束限定允许值。
- 金额字段使用 `numeric(14,2)`，并通过约束禁止负数。
- 常用查询索引均以 `tenant_id, is_deleted` 开头。
- 唯一约束采用部分唯一索引，只约束未删除记录。
- 住宿成本、酒店付款、财务结算不在本模块直接完成。

## 表清单

| 表名 | 作用 |
| --- | --- |
| `controlled_room_resources` | 自营酒店房源档案表，维护酒店、所在地、星钻标准、联系人和使用权有效期。 |
| `controlled_room_types` | 自营房型表，维护自营酒店下的房型、床型、可住人数、采购价、协议价。 |
| `controlled_room_units` | 自营房号明细表，维护自营房源下的具体房号；资源采购房源不维护房号。 |
| `room_inventories` | 房态聚合库存表，按来源、酒店、房型、日期维护总量、已锁、已占和余量。 |
| `controlled_room_lock_records` | 房态锁房流水表，记录按房型数量锁房、释放和转占用过程。 |
| `controlled_room_day_statuses` | 自营房号每日状态表，兼容后续按具体房号排房和维修停用。 |

## `controlled_room_resources`

自营酒店房源档案表。酒店层只保存酒店和使用权资料，不再把标间、大床房、三人间分别建成多条酒店档案。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `tenant_id` | 租户 ID，标识该房源属于哪一家地接公司。 |
| `hotel_name` | 酒店名称。 |
| `province` / `city` / `district` | 酒店所在地，前端使用所在地级联选择器。 |
| `area` | 酒店所在商圈或片区。 |
| `address` | 酒店详细地址。 |
| `star_standard` | 星级、钻级或内部住宿标准，后续排房按该字段匹配团队住宿标准。 |
| `source_name` | 房源来源或酒店方名称，普通文本，不关联采购供应商。 |
| `valid_from` / `valid_to` | 房源使用权有效期。 |
| `contact_name` / `contact_phone` | 房源联系人和电话。 |
| `status` | 自营酒店房源状态：`active` 启用，`disabled` 停用，`expired` 到期。 |
| `room_type` / `purchase_price` / `agreement_price` / `price_unit` | 历史兼容字段，新业务口径放到 `controlled_room_types`。 |

约束：

- 有效期结束日期不能早于开始日期。
- 同一租户下，未删除的酒店和有效期不能重复。

## `controlled_room_types`

自营房型表。一个自营酒店下面可以维护多个房型，例如标间、大床房、三人间。房型层保存价格，避免重复维护酒店档案。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `resource_id` | 所属自营酒店房源 ID。 |
| `room_type` | 房型名称。 |
| `bed_type` | 床型。 |
| `capacity` | 可住人数。 |
| `purchase_price` | 采购价，单位元。 |
| `agreement_price` | 协议价，单位元。 |
| `price_unit` | 价格单位，默认 `间夜`。 |
| `status` | 房型状态：`active` 启用，`disabled` 停用。 |

约束：

- 可住人数不能小于 0。
- 采购价和协议价不能小于 0。
- 同一自营酒店下，未删除房型名称不能重复。

## `controlled_room_units`

自营房号明细表，用于维护自营房源下的具体房号。它是可选能力，不影响计调先按房型数量锁房。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `resource_id` | 所属自营酒店房源 ID。 |
| `building_name` | 楼栋名称或编号。 |
| `floor_no` | 楼层。 |
| `room_no` | 房号。 |
| `room_type` | 房型名称快照。 |
| `bed_type` | 床型。 |
| `capacity` | 可住人数。 |
| `status` | 房号状态：`active` 启用，`disabled` 停用，`maintenance` 维修。 |

约束：

- 可住人数不能小于 0。
- 同一自营酒店下，未删除房号不能重复。

## `room_inventories`

房态聚合库存表，是后续排房联动的主表。它按来源、房型和日期维护库存数量。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `source_type` | 房源来源类型：`self_owned` 自营房源，`purchased_resource` 资源采购房源。 |
| `source_id` | 来源 ID。自营房源为 `controlled_room_resources.id`，资源采购房源为 `purchase_relations.id`。 |
| `room_type_id` | 自营房型 ID。资源采购房源为空。 |
| `hotel_name` | 酒店名称快照。 |
| `supplier_name` | 供应商名称快照，自营房源可为空。 |
| `room_type` | 房型名称快照。 |
| `stay_date` | 住宿日期。 |
| `total_quantity` | 总库存间数。 |
| `locked_quantity` | 已锁定间数。 |
| `occupied_quantity` | 已占用间数。 |
| `remaining_quantity` | 剩余可用间数。 |
| `status` | 库存状态：`active` 有效，`stopped` 停售。 |

约束：

- 数量不能小于 0。
- 已锁、已占、余量之和不能超过总量。
- 同一租户、来源、房型和日期只能有一条未删除库存。

## `controlled_room_lock_records`

房态锁房流水表。锁房记录保存团队、日期、房型和数量，是点击库存余量反查团队占用的依据。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `source_type` | 房源来源类型。 |
| `source_id` | 房源来源 ID。 |
| `room_type_id` | 自营房型 ID，资源采购房源可为空。 |
| `room_type` | 房型名称快照。 |
| `quantity` | 锁房数量。 |
| `room_id` | 具体房号 ID；按房型数量锁房时为空。 |
| `check_in_date` | 入住日期，包含当天。 |
| `check_out_date` | 退房日期，不包含当天。 |
| `team_no` / `team_name` | 团队编号和团队名称快照。 |
| `required_standard` | 团队住宿标准，用于和房源星钻标准做差异提醒。 |
| `status` | 锁房状态：`locked` 已锁定，`occupied` 已转占用，`released` 已释放。 |
| `released_at` / `released_by` | 释放时间和释放人。 |

约束：

- 退房日期必须晚于入住日期。
- 锁房数量必须大于 0。
- 来源类型只能是自营房源或资源采购房源。

## `controlled_room_day_statuses`

自营房号每日状态表，用于后续按具体房号排房、维修停用或保留房。当前主排房视图优先使用 `room_inventories`。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `resource_id` | 自营酒店房源 ID。 |
| `room_id` | 具体房号 ID。 |
| `stay_date` | 住宿日期。 |
| `status` | 房号状态：`available` 可用，`locked` 已锁定，`occupied` 已占用，`maintenance` 维修，`reserved` 保留。 |
| `lock_record_id` | 当前锁房流水 ID。 |
| `team_no` / `team_name` | 当前锁定或占用团队编号和名称快照。 |

约束：

- 同一租户、同一房号、同一日期只能有一条未删除状态。

## 与其他模块边界

- `采购管理 / 资源采购管理` 负责外部酒店资源档案。
- `采购管理 / 采购关系管理` 负责外部酒店资源与供应商、采购关系、价格基础资料。
- `计调操作 / 房态库存` 负责把自营房源和资源采购房源转为按日期可用的排房库存。
- 点击库存余量或占用数量时，可通过锁房流水反查对应团队。
- 住宿成本、酒店付款、财务结算由后续计调确认和财务模块处理。
