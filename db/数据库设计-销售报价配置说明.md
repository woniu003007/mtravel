# 数据库设计：销售报价配置说明

本文档说明 `032_sales_quote_config_schema.sql` 新增的销售报价配置表，以及 `035_sales_quote_resource_quote_mode.sql` 对普通资源报价方式的补充。  
本模块维护销售报价规则，不保存供应商采购成本；采购成本仍由资源和供应商绑定关系维护。

## 表清单

| 表名 | 作用 |
| --- | --- |
| `sales_quote_resource_rules` | 普通资源销售报价规则。按资源类型和客户等级维护采购成本基础上的建议比例上浮、最低比例上浮、建议固定加价和最低固定加价，并限定允许使用的报价方式。 |
| `sales_quote_guide_levels` | 导游等级配置。导游档案单选等级，导游报价规则按等级匹配。 |
| `sales_quote_guide_rules` | 导游报价规则。按导游等级和服务语种维护基础导服费、外语加价和超时费。 |
| `sales_quote_ground_agent_rules` | 地接报价规则。按人数区间维护整团打包价。 |
| `sales_quote_approval_members` | 销售报价低价审批人员配置。所有报价类型共用一套审批人和抄送人。 |

## sales_quote_resource_rules 字段

| 字段名 | 字段含义 |
| --- | --- |
| `id` | 报价规则主键 ID。 |
| `tenant_id` | 租户 ID。 |
| `resource_type` | 资源类型。允许值为 `scenic`、`hotel`、`restaurant`、`vehicle`、`transport`、`other`、`misc`。购物不进入本规则。 |
| `customer_category_id` | 客户等级或分类 ID。为空表示不区分客户等级的默认规则。 |
| `customer_category_name` | 客户等级或分类名称快照。 |
| `quote_mode` | 报价方式。`rate` 按比例报价，`fixed` 按固定加价报价，`both` 两种方式都可以报价；默认 `both`，兼容已有规则。 |
| `suggested_markup_rate` | 建议比例上浮，`0.1000` 表示在采购成本上上浮 10%。 |
| `minimum_markup_rate` | 最低比例上浮，低于该比例计算的销售价需要触发报价审批。 |
| `suggested_fixed_markup` | 建议固定加价金额，报价人选择固定加价方式时使用。 |
| `minimum_fixed_markup` | 最低固定加价金额，低于该金额计算的销售价需要触发报价审批。 |
| `status` | 状态。`active` 启用，`disabled` 停用。 |
| `remark` | 规则备注。 |

同一租户、同一资源类型、同一客户等级只允许一条未删除规则。`customer_category_id` 为空时代表该资源类型默认规则。

正式报价必须按 `quote_mode` 选择可用计算方式：`rate` 仅允许比例上浮，`fixed` 仅允许固定加价，`both` 可由报价人选择任一方式。未被当前方式使用的参数仅保留为规则配置值，不参与本次报价计算。

## sales_quote_guide_levels 字段

| 字段名 | 字段含义 |
| --- | --- |
| `id` | 导游等级主键 ID。 |
| `tenant_id` | 租户 ID。 |
| `level_name` | 导游等级名称。 |
| `sort_order` | 排序号，数字越小越靠前。 |
| `status` | 状态。`active` 启用，`disabled` 停用。 |
| `remark` | 等级备注。 |

系统初始化时为每个租户补充 `普通`、`资深`、`金牌` 三个启用等级。导游标签继续保留为多选能力标签，不参与报价。

`enterprise_guides` 同步增加：

| 字段名 | 字段含义 |
| --- | --- |
| `guide_level_id` | 导游等级 ID，关联 `sales_quote_guide_levels`。 |
| `guide_level_name` | 导游等级名称快照，用于列表快速展示。 |

## sales_quote_guide_rules 字段

| 字段名 | 字段含义 |
| --- | --- |
| `id` | 导游报价规则主键 ID。 |
| `tenant_id` | 租户 ID。 |
| `guide_level_id` | 导游等级 ID。 |
| `guide_level_name` | 导游等级名称快照。 |
| `language` | 服务语种。普通话表示不额外计算外语服务加价。 |
| `base_daily_fee` | 基础导服费，按天计费。 |
| `foreign_language_daily_markup` | 外语服务加价，作为基础导服费之外的按天加价。 |
| `overtime_hourly_fee` | 超时费，按小时计费。 |
| `status` | 状态。`active` 启用，`disabled` 停用。 |
| `remark` | 规则备注。 |

导游报价计算口径：

```text
基础导服费 × 服务天数
+ 外语服务加价 × 外语服务天数
+ 超时费 × 超时小时
```

导游报价不使用客户等级、比例上浮和固定加价。

## sales_quote_ground_agent_rules 字段

| 字段名 | 字段含义 |
| --- | --- |
| `id` | 地接报价规则主键 ID。 |
| `tenant_id` | 租户 ID。 |
| `min_people` | 适用最小人数，包含边界。 |
| `max_people` | 适用最大人数，包含边界。 |
| `group_package_price` | 整团打包价，不是人均价。 |
| `status` | 状态。`active` 启用，`disabled` 停用。 |
| `remark` | 规则备注。 |

同一租户未删除地接规则的人数区间不能重叠。数据库约束保证最小人数不小于 1、最大人数不小于最小人数，服务层负责重叠校验。

## sales_quote_approval_members 字段

| 字段名 | 字段含义 |
| --- | --- |
| `id` | 审批人员配置主键 ID。 |
| `tenant_id` | 租户 ID。 |
| `member_type` | 人员类型。`approver` 审批人，`cc` 抄送人。 |
| `system_user_id` | 指定系统用户 ID。 |
| `step_order` | 审批顺序。审批人从 1 开始，抄送人为 0。 |
| `created_by` | 创建人账号。 |

所有报价类型共用一套低价审批配置。审批人必须明确指定；抄送人只在审批通过后可见，具体审批申请表后续在销售报价保存模块中记录快照。

## 状态、软删除和索引

所有新增业务表均包含 `tenant_id`、`status`、`is_deleted`、`deleted_at`、`deleted_by` 等基础字段。  
常规查询必须带 `tenant_id` 和 `is_deleted = false`。高频列表和匹配路径已按租户、状态、资源类型、导游等级和人数区间建立索引。
