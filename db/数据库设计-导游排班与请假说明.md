# 导游排班与请假表说明

本文件说明 `015_dispatch_guide_schedule_schema.sql` 中的团队导游安排和导游请假记录。导游排班汇总不是独立录入排班，而是按团队导游安排和导游请假记录聚合展示。

## 设计原则

- 导游档案只维护基础资料和长期启停状态，短期请假或不可上团不写入 `enterprise_guides.status`。
- 团队导游安排是正式团队执行数据，关联 `sales_teams` 和 `enterprise_guides`。
- 导游请假记录支持两种来源：导游自己申请、计调直接设置。
- 已通过请假和计调直设请假会阻断团队导游安排；待审批请假只用于审批列表和排班提醒。
- 同一导游的团队安排、已通过请假必须按时间段做冲突校验。

## 表清单

| 表名 | 作用 |
| --- | --- |
| `dispatch_team_guides` | 团队导游安排表，保存导游、导服费、备用金、操作费、上团/下团时间、备注和待定状态。 |
| `dispatch_guide_leave_records` | 导游请假记录表，保存导游申请、计调审批和计调直接设置的不可上团时间。 |

## 关键字段

### `dispatch_team_guides`

| 字段 | 说明 |
| --- | --- |
| `team_id` / `team_no` | 所属团队 ID 和团队编号快照。 |
| `guide_id` / `guide_name` / `guide_mobile` | 带团导游 ID、姓名和手机快照。 |
| `guide_fee` | 导服费。 |
| `imprest_amount` | 备用金申请或预计金额。 |
| `operation_fee` | 操作费。 |
| `start_at` / `end_at` | 上团和下团时间。 |
| `fee_memo` | 费用说明。 |
| `guide_memo` | 导游备注。 |
| `is_tentative` | 是否待定中。 |
| `status` | `active` 生效，`cancelled` 已取消。 |

### `dispatch_guide_leave_records`

| 字段 | 说明 |
| --- | --- |
| `guide_id` / `guide_name` / `guide_mobile` | 请假导游 ID、姓名和手机快照。 |
| `source_type` | `guide_apply` 导游申请，`dispatcher_direct` 计调直接设置。 |
| `start_at` / `end_at` | 请假开始和结束时间。 |
| `leave_reason` | 请假原因或不可上团原因。 |
| `status` | `pending` 待审批，`approved` 已通过，`rejected` 已驳回，`withdrawn` 已撤回，`cancelled` 已取消。 |
| `applicant` / `applied_at` | 申请人和申请时间。 |
| `approved_by` / `approved_at` | 审批通过人和通过时间。 |
| `rejected_by` / `rejected_at` | 驳回人和驳回时间。 |
| `approval_remark` | 审批意见。 |
| `withdrawn_by` / `withdrawn_at` | 撤回人和撤回时间。 |

## 冲突规则

- 时间段冲突判断使用半开区间：`existing.start_at < new.end_at AND existing.end_at > new.start_at`。
- 新增或修改团队导游安排时，检查同导游已生效团队安排和已通过请假。
- 审批通过请假或计调直接设置请假时，检查同导游已生效团队安排。
- 导游提交待审批请假时允许保存，审批通过时再做硬拦截，避免导游无法提交诉求。
- 团队导游安排软删除或取消后不再参与冲突。
- 已驳回、已撤回、已取消请假不参与冲突。

## 排班汇总来源

导游排班汇总按开始日期生成日期列，并从两个表读取占用：

- `dispatch_team_guides`：显示为团队占用块，内容包括上团时间、团号、下团时间，点击进入团队安排导游区域。
- `dispatch_guide_leave_records`：显示为请假占用块，内容包括请假或不可上团原因、开始和结束时间。

## 模块边界

- 本模块只处理导游安排、请假和排班占用。
- 导游备用金审批、导游报账、导游结算、企业码真实额度发放不在本表范围内。
- 后续接入备用金或报账后，可基于这些业务状态锁定导游更换，但不改变本表的排班来源职责。
