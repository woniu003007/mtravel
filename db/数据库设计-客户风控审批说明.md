# 数据库设计：客户风控审批表说明

## 表作用

`customer_risk_approval_requests` 用于保存客户合同到期、授信超限时的客户授信审批申请、审批结果和申请时快照。

该表是风控授权流水，不是订单价格明细、费用变更、真实收款、成本、付款或发票表。收客订单保存时只引用已通过的审批申请，作为允许风险订单继续保存的依据。

## 字段说明

| 字段 | 说明 |
| --- | --- |
| `id` | 客户风控审批申请主键 ID。 |
| `tenant_id` | 租户 ID，用于隔离不同地接公司的审批数据。 |
| `customer_id` | 客户单位 ID。 |
| `customer_name` | 客户单位名称快照。 |
| `team_id` | 关联团队 ID，可为空。 |
| `order_id` | 关联订单 ID，新订单申请时可为空，保存后可回填。 |
| `request_no` | 审批申请编号，同一租户下未删除申请唯一。 |
| `requested_amount` | 本次订单预计应收金额。 |
| `risk_types` | 风险类型编码，多个类型用英文逗号分隔，例如 `contract_expired,credit_over_limit`。 |
| `risk_summary` | 风险摘要，面向审批人展示。 |
| `contract_expire_date` | 申请时客户合同有效期止快照。 |
| `credit_limit` | 申请时客户授信额度快照。 |
| `occupied_amount` | 申请时客户已占用额度快照。 |
| `pending_approval_amount` | 申请时客户审批中额度快照。 |
| `available_amount` | 申请时客户可用额度快照，可能为负数。 |
| `over_limit_amount` | 申请时本次订单超出可用额度的金额。 |
| `category_id` | 申请时客户等级或分类 ID 快照关联。 |
| `category_name` | 申请时客户等级或分类名称快照。 |
| `credit_term_days` | 申请时客户等级配置的账期天数快照。 |
| `current_approval_step` | 当前等待处理的审批步骤序号，从1开始。 |
| `applicant_user_id` | 发起审批的系统用户 ID。 |
| `status` | 审批状态。pending 待审批，approved 已同意，rejected 已拒绝，cancelled 已取消。 |
| `applicant` | 申请人账号或名称。 |
| `approved_by` | 同意审批人账号或名称。 |
| `approved_at` | 同意审批时间。 |
| `rejected_by` | 拒绝审批人账号或名称。 |
| `rejected_at` | 拒绝审批时间。 |
| `approval_remark` | 审批意见。 |
| `created_by` | 创建人账号或名称。 |
| `remark` | 申请备注。 |
| `created_at` | 创建时间。 |
| `updated_at` | 更新时间，由触发器自动维护。 |
| `is_deleted` | 是否已软删除。false 正常，true 已删除。 |
| `deleted_at` | 软删除时间。 |
| `deleted_by` | 执行软删除的操作人。 |

## 状态规则

| 状态 | 含义 | 允许操作 |
| --- | --- | --- |
| `pending` | 申请已提交，等待客户等级配置的当前审批人处理。 | 当前指定审批人可以同意或拒绝。 |
| `approved` | 审批已同意。 | 可被订单保存引用。 |
| `rejected` | 审批已拒绝。 | 不能被订单保存引用。 |
| `cancelled` | 审批已取消。 | 不能被订单保存引用。 |

## 订单保存联动

- `system_configs.customer_risk_approval_enabled=false` 时，收客页提示风险，后端不阻断订单保存。
- 开启后，风险订单必须由客户等级配置的指定审批人按顺序全部通过；申请人不能审批自己的申请，审批通过后才向配置的抄送人展示。
- `system_configs.customer_risk_approval_enabled=true` 时，订单保存前复查客户合同和授信额度。
- 存在 `contract_expired` 或 `credit_over_limit` 风险时，保存请求必须传入已通过的 `riskApprovalRequestId`。
- 审批申请必须与当前客户一致；如审批单已绑定团队或订单，也必须与当前团队、订单一致。
- 审批申请金额必须大于或等于当前订单预计应收金额，否则需要重新申请。
- 风控校验接口会返回同客户、同团队、同订单或未绑定订单且金额足够的最新已通过审批单，收客页自动复用该审批单，不重复生成新的待审批申请。
- 同一租户、同一订单只允许一张未删除且 `approved` 的风控审批单；如历史数据出现重复，保留最新已同意记录有效，其余重复记录转为 `cancelled`。
- 审批单绑定订单时必须与订单当前客户一致；订单客户为空或客户不一致时，审批单不能作为该订单的有效授权。

## 约束与索引

| 名称 | 作用 |
| --- | --- |
| `fk_customer_risk_approval_customer` | 审批申请关联客户单位。 |
| `fk_customer_risk_approval_team` | 审批申请关联团队。 |
| `fk_customer_risk_approval_order` | 审批申请关联订单。 |
| `chk_customer_risk_approval_status` | 限制审批状态只能为 pending、approved、rejected、cancelled。 |
| `chk_customer_risk_approval_requested_amount` | 限制申请金额不能为负数。 |
| `chk_customer_risk_approval_snapshot_amounts` | 限制授信额度、已占用额度、审批中额度和超限金额不能为负数。 |
| `uk_customer_risk_approval_tenant_request_no_active` | 同一租户下未删除审批申请编号唯一。 |
| `idx_customer_risk_approval_tenant_status_time` | 按租户、状态和创建时间查询审批申请。 |
| `idx_customer_risk_approval_tenant_customer_status` | 按客户和状态查询审批申请。 |
| `idx_customer_risk_approval_tenant_team_order` | 按团队和订单追溯审批申请。 |
| `idx_customer_risk_approval_tenant_applicant_time` | 按申请人和创建时间查询审批申请。 |
| `uk_customer_risk_approval_tenant_order_approved_active` | 约束同一租户同一订单只能有一张未删除且已同意的风控审批单。 |
