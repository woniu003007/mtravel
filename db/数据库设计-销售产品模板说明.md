# 销售产品模板表说明

本文件说明 `011_sales_product_schema.sql` 中的销售产品模板表。产品管理按线路模板设计，给后续团期、团队收客、行程单、确认件和计调安排提供基础资料。

## 设计原则

- 产品是线路模板，不是简单商品资料。
- 产品主档、每日行程、每日路书地点、产品说明、团队安排参数、安排价格明细、用车报价快照、用车询价记录和用车历史候选分表保存。
- 产品按 `tenant_id` 做多租户隔离。
- 产品、行程、说明、团队安排参数和价格明细默认软删除，不做业务物理删除。
- `status`、`trip_type`、`domestic_international`、`arrangement_type`、`settlement_type` 均通过 `CHECK` 约束限定允许值。
- 同一租户下未删除产品名称唯一。

## 表清单

| 表名 | 作用 |
| --- | --- |
| `sales_products` | 销售产品模板主表，维护产品名称、业务类型、接团城市、出团类型、标准、主题、天数、截止收客、单房差和预控人数。 |
| `sales_product_itinerary_days` | 销售产品每日行程表，按天维护行程标题、内容、住宿、关联酒店、三餐和路书汇总。 |
| `sales_product_roadbook_points` | 销售产品每日路书地点表，保存地图选点、地点顺序、到下一站距离和预计车程。 |
| `sales_product_descriptions` | 销售产品说明表，维护收客须知、费用包含、不含、儿童安排、购物、自费、赠送、注意事项和温馨提醒。 |
| `sales_product_arrangement_items` | 销售产品团队安排参数表，维护产品模板下的大交通、住宿、用车、景区、用餐等默认安排和费用参考。 |
| `sales_product_arrangement_price_lines` | 销售产品团队安排价格明细表，维护一条安排下多行价格项目，例如住宿房型、景区票种、购物品类。 |
| `vehicle_quote_rules` | 座位数报价规则表，维护按车辆座位数、基础公里、超公里单价和浮动系数测算用车参考价的规则。 |
| `sales_product_vehicle_quote_snapshots` | 销售产品用车报价测算快照表，保存某个用车安排当时同步的路书公里、命中规则和测算金额。 |
| `sales_product_vehicle_inquiries` | 销售产品用车询价记录表，保存业务人员通过微信群、电话等方式向多家车队询价后的报价记录。 |
| `vehicle_usage_histories` | 用车历史候选表，沉淀用车安排中手动输入的司机信息和车牌号，供下次按使用次数下拉选择。 |

## 关键字段

### `sales_products`

| 字段 | 说明 |
| --- | --- |
| `product_name` | 产品名称，也就是线路名称。 |
| `business_type` | 业务类型，从产品字典选择。 |
| `domestic_international` | `domestic` 国内，`international` 国际。 |
| `province` / `city` / `district` | 接团所在地。 |
| `trip_type` | `daily` 每天发，`weekly` 每周发，`irregular` 不定期。 |
| `reception_standard` | 接待标准，从产品字典选择。 |
| `product_theme` | 产品主题，从产品字典选择。 |
| `travel_days` | 旅游天数。 |
| `close_days_before` | 截止收客天数。 |
| `single_room_difference` | 单人房差金额。 |
| `planned_capacity` | 预控人数，用于后续生成团期时参考。 |
| `status` | `active` 启用，`disabled` 停用。 |

### `sales_product_itinerary_days`

| 字段 | 说明 |

| `accommodation_note` | 住宿说明。 |
| `related_hotel` | 关联酒店名称或说明。 |

| `breakfast_included` / `lunch_included` / `dinner_included` | 当日是否含早中晚餐。 |
| `roadbook_place` | 兼容旧版的路书地点或关键途经地点。 |
| `roadbook_summary` | 当天路线摘要，例如出发地到景区再到酒店。 |
| `roadbook_total_distance_meters` | 当天路书总距离，单位米。 |
| `roadbook_total_duration_seconds` | 当天路书预计总车程，单位秒。 |

### `vehicle_quote_rules`

| 字段 | 说明 |
| --- | --- |
| `vehicle_type` | 车辆座位数，例如 7座、39座。字段名沿用 vehicle_type，页面展示为“座位数”。 |
| `province` / `city` / `district` | 预留地区字段，当前座位数报价规则页面暂不启用，保存时统一为空。 |
| `base_price` | 基础价。 |
| `base_kilometers` | 基础公里数，路书公里未超过该值时先按基础价测算。 |
| `extra_kilometer_price` | 超出基础公里后的每公里参考价。 |
| `minimum_price` | 最低参考价。 |
| `float_rate` | 浮动系数，例如 1.10 表示上浮 10%。 |
| `status` | `active` 启用，`disabled` 停用。 |

启用的座位数报价规则会同步补齐同名车队费用项目，例如 `60座` 会写入 `resource_projects(resource_type='vehicle', project_name='60座')`。同步只补齐或启用费用项目，不删除已被历史采购价格和团队安排快照引用的项目；未被引用的早期描述型车型种子，例如 `7座商务车`、`19座中巴`、`33座大巴`，通过数据补丁软删除，避免用车价格信息下拉重复。

## 模块边界

- 本模块只维护产品模板资料。
- 团期管理、创建团队、正式排团、余位和订单收客由后续销售团队链路实现。
- 团队安排参数和价格明细只作为模板默认值和费用参考，不等于计调正式履约记录。
- 用车报价规则用于测算参考价，不直接生成正式派车成本；正式团队安排阶段仍需按实际询价和确认结果落成本。
- 产品用车报价快照必须保存当时命中的规则价格参数，后续报价规则调整不能反向改变历史产品模板中的参考价。
- 用车询价记录用于登记微信群、电话等线下询价结果，不建设车队登录端或外部报价门户。
- 当前产品模板阶段没有正式订单、正式团队成本、导游报账和计调审核数据；这些字段只是为后续正式团队安排页面提供默认带入口径。
- 座位数报价规则当前只按车辆座位数和路书公里测算参考价，暂不按省市区维护多套规则。
- 座位数报价规则和车队费用项目保持同名补齐，用于让用车弹窗的座位数和价格信息项目对齐；旧的 `33座大巴`、`车费` 等费用项目不自动改名或删除。
- 路书地点用于产品模板和后续车调估价参考，正式团队行程执行时仍需按团期和团队实际日期确认。
- 产品字典由 `product_dictionaries` 维护，产品表保存当时选择的字典名称，便于历史产品展示。
- 用车历史候选不是司机档案或车辆档案，只服务于手动输入的快速回填；是否建设正式车辆档案和司机档案由后续团队安排/车辆管理模块决定。
