# 产品字典表说明

本文件说明 `010_product_dictionary_schema.sql` 中的产品字典表。该表用于企业资料下的产品字典维护，给后续销售产品模板和团期计划提供统一下拉选项。

## 设计原则

- 产品字典按 `tenant_id` 做多租户隔离。
- 字典数据默认软删除，不做业务物理删除。
- `dict_type` 使用 `varchar(40)` 并通过 `CHECK` 约束限定为业务类型、接待标准和产品主题。
- `status` 使用 `varchar(20)` 并通过 `CHECK` 约束限定为启用或停用。
- 同一租户、同一字典类型下，未删除的字典名称唯一。
- 表和字段注释只写业务含义，不写来源追踪口径。

## 表清单

| 表名 | 作用 |
| --- | --- |
| `product_dictionaries` | 产品字典表，维护产品模板可选择的业务类型、接待标准和产品主题。 |

## `product_dictionaries`

该表用于维护销售产品模板的基础选项。产品管理后续只引用这里的启用字典，不在产品页面临时维护选项。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `tenant_id` | 租户 ID，标识字典属于哪一家地接公司。 |
| `dict_type` | 字典类型。`business_type` 业务类型，`reception_standard` 接待标准，`product_theme` 产品主题。 |
| `dict_name` | 字典名称，用于产品模板页面展示和保存。 |
| `sort_order` | 排序值。数字越小越靠前。 |
| `status` | `active` 启用，`disabled` 停用。 |
| `created_by` | 创建人账号或名称。 |
| `remark` | 备注，用于记录产品字典管理说明。 |
| `is_deleted` | 是否已删除。`false` 正常，`true` 已软删除。 |
| `deleted_at` / `deleted_by` | 软删除时间和删除人。 |

约束：

- `dict_type` 只允许 `business_type`、`reception_standard`、`product_theme`。
- `sort_order` 必须大于等于 0。
- `status` 只允许 `active`、`disabled`。
- 同一租户、同一字典类型下，未删除的 `dict_name` 唯一。
- 删除只更新软删除字段，不物理删除。

初始化数据：

- `business_type`：疗休养、定制团、红色培训、门票冲量、特惠游、漂流、落地散、地接团、周边游、办公费用、杂项经费。
- `reception_standard`：商务/快捷、携程两钻、准三星、挂牌三星、携程三钻、挂牌四星、准四星、当地四星、国际四星、携程四钻、准五星、挂牌五星、当地五星、国际五星、携程五钻、超五星级、其它等级。
- `product_theme`：观光、美食、夕阳红、亲子游、摄影、滑雪、夏令营、春节、五一、中秋、国庆、元旦。

## 后续联动范围

- 销售产品模板：选择业务类型、接待标准和产品主题。
- 团期计划：继承产品模板中的字典值，用于筛选、展示和统计。
- 产品筛选：按业务类型、接待标准或产品主题过滤产品。
- 数据统计：后续可按业务类型或主题分析产品和团队业务结构。
