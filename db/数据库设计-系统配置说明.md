# 数据库设计：系统配置表说明

## 表作用

`system_configs` 用于保存每个租户可独立设置的运行参数。第一阶段先用于登录安全配置，例如浏览器长时间无操作后的自动退出时间。

本表是多租户配置表，必须通过 `tenant_id` 区分不同地接公司的配置。

## 字段说明

| 字段 | 说明 |
| --- | --- |
| `id` | 系统配置主键 ID，系统内部使用。 |
| `tenant_id` | 租户 ID，标识该配置属于哪一家地接公司。 |
| `config_key` | 配置键，使用稳定英文编码标识具体配置项。 |
| `config_value` | 配置值，按配置键约定保存数字、文本或布尔值。 |
| `remark` | 配置说明，用于解释该配置项的业务含义和单位。 |
| `created_at` | 创建时间。 |
| `updated_at` | 更新时间，由触发器自动维护。 |

## 当前配置项

| 配置键 | 说明 | 默认值 |
| --- | --- | --- |
| `login_idle_timeout_minutes` | 浏览器无操作自动退出时间，单位分钟。 | `120` |
| `map.amap.web_service_key` | 高德地图 Web 服务 Key，用于后端代理地点搜索和驾车路线计算。 | 无默认值，必须由系统配置或环境变量提供。 |
| `map.amap.js_key` | 高德 Web 端 JavaScript API Key，用于前端交互地图加载。 | 无默认值；未配置时开发环境临时回退使用 Web 服务 Key。 |
| `map.amap.js_security_code` | 高德 JavaScript API 2.0 安全密钥，用于浏览器端地图安全校验。 | 无默认值，正式环境建议配置。 |

## 约束与索引

| 名称 | 作用 |
| --- | --- |
| `uk_system_configs_tenant_key` | 同一租户下同一个配置键只能有一条记录。 |
| `idx_system_configs_tenant_key` | 按租户和配置键查询系统配置。 |

## 登录配置规则

- 后端登录会话以 Redis TTL 为准，浏览器端计时只用于提升用户体验。
- 配置值为空、缺失或格式不合法时，后端使用应用默认值。
- 默认无操作退出时间为 `120` 分钟。
- 后续如需新增登录失败锁定、密码有效期等配置，继续在本表按配置键扩展。

## 地图配置规则

- 地点搜索和驾车路线计算走后端代理接口。
- 产品路书交互地图使用高德 JavaScript API，前端只从后端读取 `map.amap.js_key` 和 `map.amap.js_security_code` 配置。
- `map.amap.web_service_key` 缺失时，后端可回退读取运行环境变量 `AMAP_WEB_SERVICE_KEY`。
- 配置文档和代码中不能记录真实 Key 值，真实值只允许存在于运行环境或数据库配置表中。
