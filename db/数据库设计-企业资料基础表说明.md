# 企业资料基础表说明

本文件说明 `006_enterprise_basic_schema.sql` 中的企业资料基础表。当前包含企业银行账号、企业公司信息、企业部门、企业角色、角色权限、企业员工、导游档案、导游标签和导游标签关系资料。

## 设计原则

- 企业基础资料均按 `tenant_id` 做多租户隔离。
- 基础资料默认软删除，不做业务物理删除。
- `status` 使用 `varchar(20)`，并通过 `CHECK` 约束限定取值。
- 常用查询索引以 `tenant_id, is_deleted` 开头。
- 表和字段注释只写专业业务含义，不写来源说明。

## 表清单

| 表名 | 作用 |
| --- | --- |
| `enterprise_bank_accounts` | 企业银行账号表，维护企业收款、付款、打印展示和现金账授权可使用的账户资料。 |
| `enterprise_company_infos` | 企业公司信息表，维护本企业合同甲方、确认件抬头、签约账号和基础联系信息。 |
| `enterprise_departments` | 企业部门表，维护企业组织架构中的部门资料，供员工、角色、计调归属和业务统计使用。 |
| `enterprise_roles` | 企业角色表，维护后台用户角色，供员工账号归属、菜单权限入口和后续按钮权限控制使用。 |
| `enterprise_role_permissions` | 企业角色权限表，保存角色已分配的菜单、按钮或数据权限编码。 |
| `enterprise_employees` | 企业员工表，维护员工基础资料、所属部门、角色归属、登录账号和数据查看范围。 |
| `enterprise_guides` | 企业导游档案表，维护导游基础资料、证件、结算账号、企业码状态和排班结算引用信息。 |
| `enterprise_guide_tags` | 导游标签表，维护导游能力、线路经验、服务类型和内部分类标签。 |
| `enterprise_guide_tag_relations` | 导游标签关系表，维护导游档案与导游标签的多对多绑定关系。 |

## `enterprise_bank_accounts`

该表用于维护企业收付款账户。银行卡、支付宝、微信、客户现付、房券、充账等都可作为企业账户统一维护。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `bank_name` | 开户行或账户类型，例如银行名称、支付宝、微信、客户现付、房券。 |
| `account_name` | 户名或收款主体名称。 |
| `account_no` | 银行账号、支付账号或内部结算方式标识。 |
| `print_enabled` | 是否在打印单据或确认件中展示。 |
| `other_info` | 其它账户说明，例如银行地址、SWIFT、联行号或境外汇款资料。 |
| `status` | `active` 启用，`disabled` 停用。 |
| `created_by` | 创建人账号或名称。 |

约束：

- 同一租户下未删除账号 `account_no` 唯一。
- 状态只允许 `active`、`disabled`。
- 删除只更新软删除字段，不物理删除。

## 后续联动范围

本批先完成银行账号基础维护。以下联动后续在对应业务模块开发时接入：

- 收款记录选择收款账号。
- 付款记录选择付款账号。
- 导游备用金付款记录付款账号和流水信息。
- 员工现金账权限按账号授权。
- 打印确认件时按 `print_enabled` 控制是否展示账户。

## `enterprise_company_infos`

该表用于维护本企业公司信息。合同管理新增分销商合同时，甲方信息可从本表自动带出；确认件、签约链接和企业资料展示也可复用该表。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `company_name` | 公司名称，用于合同甲方、确认件抬头和企业资料展示。 |
| `province` / `city` / `district` | 公司所在省市区。 |
| `contact_name` | 公司负责人或联系人姓名。 |
| `contact_phone` | 公司联系电话。 |
| `fax_number` | 公司传真号码。 |
| `office_address` | 公司办公地址。 |
| `alipay_enterprise_name` | 支付宝企业名称。 |
| `alipay_account` | 支付宝登录账号或签约账号。 |
| `alipay_nickname` | 支付宝企业简称。 |
| `sign_status` | `unsigned` 未签约，`signed` 已签约。 |
| `sign_link` | 签约链接或外部签约地址。 |
| `status` | `active` 启用，`disabled` 停用。 |

约束：

- 同一租户下只允许保留一条未删除公司信息。
- 状态只允许 `active`、`disabled`。
- 签约状态只允许 `unsigned`、`signed`。
- 删除只更新软删除字段，不物理删除。

## `enterprise_departments`

该表用于维护企业组织架构中的部门资料。部门后续会被员工管理、角色权限、计调归属、客户业务员归属和经营统计引用，因此删除采用软删除。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `parent_id` | 上级部门 ID。为空表示一级部门。 |
| `department_code` | 部门编码，用于内部识别和外部数据导入匹配。 |
| `department_name` | 部门名称，例如销售部、计调部、财务部。 |
| `manager_name` | 部门负责人姓名。 |
| `contact_phone` | 部门联系电话或负责人联系电话。 |
| `sort_order` | 排序值。数字越小越靠前。 |
| `status` | `active` 启用，`disabled` 停用。 |
| `created_by` | 创建人账号或名称。 |

约束：

- 同一租户下未删除部门名称唯一。
- 同一租户下未删除且编码不为空的部门编码唯一。
- `parent_id` 必须引用同一租户下存在的部门。
- 状态只允许 `active`、`disabled`。
- 删除只更新软删除字段，不物理删除。
- 有未删除下级部门时，业务接口不允许删除上级部门。

后续联动范围：

- 员工管理选择所属部门。
- 角色权限按部门进行数据范围控制。
- 计调、销售、财务人员归属到部门。
- 经营统计按部门汇总业绩和操作数据。

## `enterprise_roles`

该表用于维护企业内部角色。角色会被员工账号引用，也会作为后续菜单权限、按钮权限和数据权限的配置入口。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `role_code` | 角色编码，用于登录令牌、权限判断和外部数据导入匹配。 |
| `role_name` | 角色名称，例如管理员、销售、计调、财务、总经理。 |
| `sort_order` | 排序值。数字越小越靠前。 |
| `system_builtin` | 是否系统内置角色。 |
| `status` | `active` 启用，`disabled` 停用。 |
| `created_by` | 创建人账号或名称。 |

约束：

- 同一租户下未删除角色编码唯一。
- 同一租户下未删除角色名称唯一。
- 状态只允许 `active`、`disabled`。
- 删除只更新软删除字段，不物理删除。
- 已被员工引用的角色，业务接口不允许删除。

初始化角色：

| 角色编码 | 角色名称 | 说明 |
| --- | --- | --- |
| `admin` | 管理员 | 系统管理、基础资料维护和权限配置角色。 |
| `sales` | 销售 | 销售收客、订单和客户资料维护角色。 |
| `dispatch` | 计调 | 团队安排、履约跟进和计调审核角色。 |
| `finance` | 财务 | 收付款、审核和结算管理角色。 |
| `boss` | 总经理 | 经营统计、全局看数和管理决策角色。 |

## `enterprise_role_permissions`

该表用于保存角色已分配的权限编码。首版先提供权限管理入口，不一次性做完整按钮拦截；后续菜单和按钮稳定后，权限编码可直接被拦截器或前端菜单过滤逻辑使用。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `role_id` | 角色 ID。 |
| `module_code` | 模块编码，用于按业务模块分组展示权限。 |
| `module_name` | 模块名称，例如客户管理、销售管理、计调操作、财务管理。 |
| `permission_code` | 权限编码，用于菜单、按钮或数据范围判断。 |
| `permission_name` | 权限名称，用于权限管理界面展示。 |
| `permission_type` | 权限类型。`menu` 菜单，`button` 按钮，`data` 数据范围。 |
| `sort_order` | 排序值。数字越小越靠前。 |

约束：

- `role_id` 必须引用同一租户下存在的角色。
- 同一租户、同一角色下未删除权限编码唯一。
- 权限类型只允许 `menu`、`button`、`data`。
- 删除只更新软删除字段，不物理删除。

## `enterprise_employees`

该表用于维护员工名录，并与 `system_users` 登录账号形成一体化关系。创建员工时同时创建登录账号；停用或删除员工时同步停用或软删除登录账号。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `system_user_id` | 系统用户 ID，用于关联后台登录账号。 |
| `employee_code` | 员工业务编码，用于业务归属、外部导入或内部识别。 |
| `employee_name` | 员工姓名。 |
| `username` | 登录账号冗余值，用于员工列表展示和账号查重。 |
| `department_id` | 所属部门 ID。 |
| `role_id` | 角色 ID。 |
| `gender` | `male` 男，`female` 女，`unknown` 未填写。 |
| `telephone` | 固定电话或办公室电话。 |
| `mobile_phone` | 手机号码。 |
| `email` | 邮箱地址。 |
| `info_scope` | 信息查看范围。`company` 全公司，`department` 部门范围，`personal` 个人信息。 |
| `profit_scope` | 利润查看范围。`company` 全公司，`department` 部门范围，`personal` 个人信息。 |
| `reception_scope` | 收客查看范围。`company` 全公司，`department` 部门范围，`personal` 个人信息。 |
| `customer_scope` | 客户查看范围。`company` 全公司，`department` 部门范围，`personal` 个人信息。 |
| `sort_order` | 排序值。数字越小越靠前。 |
| `status` | `active` 启用，`disabled` 停用。 |

约束：

- 同一租户下未删除员工登录账号唯一。
- 同一租户下未删除且编码不为空的员工业务编码唯一。
- 同一租户下未删除员工关联登录账号唯一。
- 所属部门必须引用同一租户下存在的部门。
- 角色必须引用同一租户下存在的角色。
- 四个查看范围字段只允许 `company`、`department`、`personal`。
- 员工删除只更新软删除字段，并同步软删除关联登录账号。

业务联动范围：

- 员工创建时生成后台登录账号，初始密码由业务服务设置。
- 员工角色变化时同步更新登录账号的角色编码。
- 员工停用时同步停用登录账号，避免停用人员继续登录。
- 销售、计调、财务等业务单据后续可引用员工 ID 和员工姓名。

## `enterprise_guides`

该表用于维护导游档案。导游是独立的排班、备用金、报账、结算和统计主体，因此不直接混入员工表。后续导游排班、导游备用金、导游结算和导游统计都应引用该表。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `guide_code` | 导游编码，用于内部识别、导入匹配和排班引用。 |
| `guide_name` | 导游姓名，用于排团、结算和统计展示。 |
| `username` | 导游端登录用户名或外部系统用户名。 |
| `guide_manager_employee_id` | 所属导管员工 ID，用于导游绩效归属、分组管理和导管统计。 |
| `guide_manager_name` | 所属导管员工姓名冗余，用于列表展示和历史归属留痕。 |
| `gender` | `male` 男，`female` 女，`unknown` 未填写。 |
| `certificate_no` | 导游证件号或导游证编号。 |
| `id_card_no` | 身份证号或身份识别号码。 |
| `telephone` | 固定电话。 |
| `fax` | 传真号码。 |
| `mobile_phone` | 手机号码。 |
| `settlement_account` | 历史结算账号字段，保留用于兼容既有数据。 |
| `bank_name` | 银行名称，用于导游结算付款资料。 |
| `bank_account_no` | 银行账号，用于导游结算付款资料。 |
| `alipay_name` | 支付宝姓名，用于备用金发放、核销退补或导游结算付款。 |
| `alipay_account` | 支付宝账号，用于备用金发放、核销退补或导游结算付款。 |
| `enterprise_code_account` | 企业码账号或企业码绑定标识。 |
| `enterprise_code_status` | 企业码状态。`not_joined` 未加入，`invite_link` 已获取签约链接，`signed_success` 已签约成功；`bound`、`unbound`、`disabled` 为兼容状态。 |
| `enterprise_code_invited_at` | 最近一次发送企业码签约邀请的时间。 |
| `status` | `active` 启用，`disabled` 停用。 |
| `age` | 年龄，用于导游展示资料和团队匹配参考。 |
| `native_place` | 籍贯，用于导游展示资料。 |
| `working_years` | 从业年数，用于导游展示资料和经验判断。 |
| `languages` | 语言能力，例如普通话、英语或其它语种。 |
| `personal_intro` | 个人介绍，用于导游展示资料。 |
| `certificate_file_url` | 导游证书附件地址。 |
| `photo_url` | 个人照片地址，用于导游展示资料。 |
| `rating` | 导游评分，取值范围 0 到 5。 |
| `total_tours` | 累计带团次数。 |
| `sort_order` | 排序值。数字越小越靠前。 |

约束：

- 同一租户下未删除且不为空的导游编码唯一。
- 同一租户下未删除且不为空的导游用户名唯一。
- 同一租户下未删除且不为空的导游证件号唯一。
- 所属导管必须引用同租户下存在的员工；为空表示暂未分配导管。
- 状态只允许 `active`、`disabled`。
- 企业码状态只允许 `not_joined`、`invite_link`、`signed_success`、`bound`、`unbound`、`disabled`。
- 年龄和从业年数不能小于 0。
- 评分范围为 0 到 5。
- 累计带团次数不能小于 0。
- 删除只更新软删除字段，不物理删除。

业务联动范围：

- 团队安排选择导游时引用导游档案。
- 导游排班汇总按导游 ID 统计占用和冲突。
- 导游备用金使用支付宝账号或结算账号发放和核销。
- 导游结算按导游 ID 汇总现付、收入、上交和差额退补。
- 导游统计按排班、报账、结算、异常和评价归集数据。
- 所属导管用于导游绩效归属和导管小组业绩统计。
- 导游标签用于能力分类、排团筛选和标签维度统计；标签不承担导管归属。

## `enterprise_guide_tags`

该表用于维护导游标签。标签用于导游能力、线路经验、服务类型和内部分类，例如金牌导游、研学、亲子、英语等。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `tag_name` | 标签名称。 |
| `status` | `active` 启用，`disabled` 停用。 |
| `sort_order` | 排序值。数字越小越靠前。 |
| `remark` | 备注，用于记录标签使用说明。 |

约束：

- 同一租户下未删除标签名称唯一。
- 状态只允许 `active`、`disabled`。
- 删除只更新软删除字段，不物理删除。

## `enterprise_guide_tag_relations`

该表用于维护导游档案和导游标签的多对多关系。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `guide_id` | 导游档案 ID。 |
| `tag_id` | 导游标签 ID。 |

约束：

- 导游 ID 必须引用同租户导游档案。
- 标签 ID 必须引用同租户导游标签。
- 同一租户下未删除的 `guide_id + tag_id` 关系唯一。
- 删除只更新软删除字段，不物理删除。
