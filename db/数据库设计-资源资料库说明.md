# 资源资料库说明

## 范围

资源资料库挂在统一采购资源主档 `purchase_resources` 下，服务景区、酒店、餐厅、购物、用车、大交通、地接和其它资源的产品编排与 Word 产品资料生成。它不归属供应商或采购关系。

现有 `knowledge_documents` 继续保存 Word、PDF、Excel、文本等原始资源文件及其抽取、审核、向量化状态。本次新增的表只服务人工维护的介绍正文和可复用图片。
如果素材被标记为自费项目介绍，还必须通过 `resource_optional_item_id` 关联到对应的资源级自费项目主档，不能只靠标题或正文猜测归属。

## `purchase_resource_introductions`

一条记录代表一份可独立选择的资源介绍版本。常见标签包括通用、简版、秋冬、亲子、研学和中老年；标签是 JSON 数组，产品生成时可按产品主题、季节和客群筛选。

- `is_optional_item`：是否为自费项目介绍；自费项目与常规介绍共用正文、温馨提示、注意事项和游览时间字段，只在素材列表和产品选材时增加“自费”标记。
- `resource_optional_item_id`：自费项目介绍对应的资源级自费项目主档 ID。常规介绍为空；自费介绍必须填写。
- `content`：必填的介绍正文，用于产品行程和产品手册生成。
- `notice_content`：选填的注意事项，按非空行逐条维护；产品资料生成时按红色提示输出，避免与正文混淆。
- `warm_tip_content`：选填的温馨提示，按非空行逐条维护；产品资料生成时按普通文字输出。
- `extension_blocks`：选填的结构化扩展内容模块 JSON 数组。当前支持 `photo_recommendation`（拍照机位推荐，橙色标题和自动编号条目）及 `warm_tip`（温馨提示，蓝色标题和自动编号条目）；模块和条目均按数组顺序输出。每份介绍最多 10 个模块，每个模块最多 20 条内容。
- `visit_duration`：选填的资源建议游览时间，例如“约2小时”，用于产品设计引用时了解资源时长。
- `sort_order`：当前资源内介绍素材的维护排序，从 1 开始。资料页拖拽保存时必须提交当前资源全部未删除素材。
- `purchase_resource_introduction_images`：当前介绍素材选用的图片关联。图片仍来自当前资源的图片素材库，介绍素材只维护选用关系和排序，不复制文件。

- `draft`：草稿，不参与产品资料推荐或向量检索。
- `published`：已发布，可用于产品生成，并异步写入介绍切片和 pgvector 向量。
- `disabled`：停用，不参与产品生成或检索。

自费素材和常规素材可以共存于同一资源下，也可以分别维护多个版本。产品生成时只会选择与当前资源和当前自费项目匹配的已发布素材，避免把普通景点介绍误当成自费项目介绍。

保存草稿、重新发布或删除时都会提升 `index_version`。异步任务只处理仍为已发布且版本一致的介绍，避免旧任务在用户修改或删除后重新写回向量。

扩展内容模块只服务产品介绍排版，不参与向量切片和检索；用户录入的正文仍是资源知识检索的主要内容。

## `purchase_resource_introduction_chunks`

该表是介绍正文、温馨提示和注意事项的检索切片。每条切片保存源介绍 ID、资源 ID、文本、token 估算值、模型名和 `vector(1024)` 向量。正文切片以 `【资源介绍正文】` 开头，温馨提示切片以 `【温馨提示】` 开头，注意事项切片以 `【注意事项】` 开头；即使长文本被拆分，检索结果也能保留业务用途。

介绍删除时，相关切片和向量按 `tenant_id + introduction_id` 物理删除；介绍主档自身保留软删除审计信息。因此已删除素材不会继续被产品生成器或后续检索服务命中。

## `purchase_resource_images`

图片素材复用 `common_attachments` 保存原始图片文件，表中只记录图片和资源的业务关系：文件名快照、标签、封面标识和排序。

- 图片归属于资源主档，可被多份介绍和多个产品重复选择。
- 每个资源最多有一张未删除且启用的封面图片。
- 图片二进制不写入 pgvector；后续若需要智能选图，只对人工维护的图片说明或标签建立额外检索数据。
- 删除图片时，图片业务记录和公共附件元数据软删除，原始文件在事务提交后清理；介绍素材和资源文件不受影响。

## `purchase_resource_introduction_images`

介绍素材图片关联表让同一资源下的不同介绍版本使用不同的景点图片组合。例如“灵山胜境通用介绍”和“九龙灌浴介绍”可以各自选用多张图片，同时复用图片素材库中的同一张原图。

- 用户可在介绍素材编辑区从当前资源的图片素材库勾选图片，也可直接上传图片；新图片先进入资源图片素材库，再自动关联到当前介绍素材。
- 一条介绍素材可关联多张图片，`sort_order` 决定产品资料和 Word 的输出顺序。
- 一张资源图片可被多个介绍素材复用；删除介绍素材只软删除关联记录，不删除图片文件。
- `remark` 只用于记录本次图片关联的内部维护说明，不参与产品展示或 Word 输出。
- 保存关联时后端同时校验介绍素材和图片属于同一租户、同一资源且图片处于启用状态，不能通过前端 ID 跨资源引用图片。

## 查询与性能

抽屉只在打开当前资源时按资源 ID 懒加载介绍、图片和文件。介绍和图片列表均以 `tenant_id + is_deleted + resource_id` 为主查询条件，避免加载无关资源数据；介绍列表额外按 `sort_order + id` 稳定读取。
