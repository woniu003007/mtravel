# 客户授信与普通资源报价规则说明

## 模块边界

本模块维护两类租户级配置：

- `customer_credit_rules`：按客户等级定义默认授信额度、账期、是否允许超额，以及审批与抄送人员配置。
- `resource_quote_rules`：按资源类型和可选客户等级定义普通资源的建议、最低报价上浮口径。

两类规则都属于配置资料，不直接替代订单应收、实际收款、团队成本或供应商应付。订单、成本和收付款仍以各自业务流水为准。

## 客户等级引用

两张规则表均通过 `(tenant_id, customer_level_id)` 引用 `customer_categories`。客户等级名称不在规则表重复保存，列表接口按当前有效分类批量组装名称。

普通资源报价规则的 `customer_level_id` 可以为空：

- 有值：仅适用于指定客户等级。
- 空值：默认规则，适用于没有更具体等级规则的场景。

编辑时前端必须明确提交 `customerLevelId: null` 才表示清空等级关联；后端不得因 MyBatis 的空字段策略忽略这次更新。

## `customer_credit_rules`

| 字段 | 说明 |
| --- | --- |
| `customer_level_id` | 必填客户等级。每个租户、每个未删除客户等级只能有一条授信规则。 |
| `credit_limit` | 默认授信额度，单位元。列表固定按该字段从小到大排序，再按 ID 稳定排序。 |
| `account_period_days` | 允许账期天数，不能为负数。 |
| `allow_over_limit` | 是否允许超出可用授信额度。 |
| `approver_employee_ids` | 按顺序保存的审批员工 ID 列表。 |
| `cc_employee_ids` | 接收通知的员工 ID 列表。 |
| `status` | `active` 启用，`disabled` 停用。 |

审批人和抄送人接口每组最多选择 50 人，确保逗号分隔的员工 ID 列表可放入数据库 `varchar(1000)` 字段。

页面“序号”是当前分页、当前额度排序下的展示序号，不写入数据库，也不提供人工排序字段。

## `resource_quote_rules`

| 字段 | 说明 |
| --- | --- |
| `resource_type` | 必填资源类型。 |
| `customer_level_id` | 可选客户等级；空值代表默认规则。 |
| `suggested_markup_rate` | 建议比例上浮，按百分数保存，`20` 表示 `20%`。 |
| `minimum_markup_rate` | 最低比例上浮，按百分数保存，`15` 表示 `15%`，不能高于建议比例。 |
| `suggested_fixed_markup` | 建议固定加价，单位元。 |
| `minimum_fixed_markup` | 最低固定加价，单位元，不能高于建议固定加价。 |
| `status` | `active` 启用，`disabled` 停用。 |

未删除数据的唯一范围为：同一租户、同一资源类型、同一客户等级只允许一条规则；其中默认规则单独保证同一资源类型最多一条。

## 查询与索引

- 授信规则列表使用 `(tenant_id, is_deleted, credit_limit, id)`，保证按额度升序分页时不扫描全部规则。
- 报价规则列表使用 `(tenant_id, is_deleted, resource_type, customer_level_id, id)`，覆盖资源类型和客户等级筛选。
- 所有查询和更新必须带 `tenant_id`、`is_deleted = false`，删除只做软删除。
