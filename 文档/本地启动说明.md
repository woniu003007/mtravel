# 本地启动说明

本文记录开发环境手动启动方式。真实数据库、Redis 密码只放在本机 `.env.local`，不要写进代码、SQL、Markdown 或提交记录。

## 首次配置

在项目根目录执行：

```bash
cp .env.example .env.local
open .env.local
```

填写 `.env.local` 中的：

```bash
DB_PASSWORD=
REDIS_PASSWORD=
```

常用配置项如下，具体主机、账号和密码按本机实际环境填写：

```bash
DB_HOST=
DB_PORT=5432
DB_NAME=mtravel
DB_USER=

REDIS_HOST=
REDIS_PORT=6379
REDIS_DATABASE=0
FLYWAY_ENABLED=false
```

`.env.local` 已被 `.gitignore` 排除，只用于本机启动。

## 启动后端

在项目根目录执行：

```bash
./start-backend.sh
```

脚本会自动：

- 读取 `.env.local`
- 设置数据库和 Redis 环境变量
- 停掉旧的 8080 后端进程
- 重新启动 Spring Boot 后端
- 等待健康检查通过

后端日志位置：

```bash
output/dev-logs/backend-8080.log
```

检查后端是否正常：

```bash
curl -s http://127.0.0.1:8080/actuator/health
```

正常返回：

```json
{"status":"UP"}
```

## 启动前端

在项目根目录执行：

```bash
./scripts/dev-frontend-restart.sh
```

默认前端地址：

```text
http://127.0.0.1:5666
```

前端日志位置：

```bash
output/dev-logs/frontend-5666.log
```

## 启动客服 Agent

首次运行先创建客服 Agent 的独立 Python 环境：

```bash
python3 -m venv customer-service-agent/.venv
customer-service-agent/.venv/bin/python -m pip install \
  -r customer-service-agent/requirements.txt
```

在 `.env.local` 中配置 `DASHSCOPE_API_KEY`。默认 `DMS_MOCK_MODE=true`，页面
使用模拟地接数据，不会创建真实询价或转人工待办。启动命令：

```bash
./scripts/dev-customer-service-agent-restart.sh
```

模拟控制台地址：

```text
http://127.0.0.1:5670/
```

日志位置：

```text
output/dev-logs/customer-service-agent-5670.log
```

需要连接真实后端时，将 `DMS_MOCK_MODE=false`。客服服务默认复用
`AGENT_SERVICE_TOKEN`，也可以用 `DMS_SERVICE_TOKEN` 单独覆盖。

## 常用联调检查

登录接口：

```bash
curl -s -X POST http://127.0.0.1:5666/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"123456"}'
```

如果返回 `code: 0`，说明前端代理和后端接口都正常。

## 常见问题

### 8080 接口挂了

先直接执行：

```bash
./start-backend.sh
```

再检查：

```bash
curl -s http://127.0.0.1:8080/actuator/health
```

### 不要直接这样启动

不推荐直接执行：

```bash
cd backend
mvn spring-boot:run
```

原因是容易丢失数据库和 Redis 环境变量，导致后端连到错误的本地默认配置。
