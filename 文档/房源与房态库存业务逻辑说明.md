# 房源与房态库存业务逻辑退役说明

甲方已确认没有自营房源，系统不再保留 `计调操作 / 自控房源与房态库存` 功能。

已退役范围：

- 前端页面：`/dispatch/room-status`
- 后端接口：`/dispatch/room-status/**`
- 数据库表：`controlled_room_resources`、`controlled_room_types`、`controlled_room_units`、`room_inventories`、`controlled_room_lock_records`、`controlled_room_day_statuses`

后续业务口径：

- 酒店档案、房型、采购价和协议价统一维护在采购管理的酒店资源中。
- 产品和团队创建页面的关联酒店下拉只读取采购酒店资源。
- 团队执行阶段的住宿费用、供应商、价格明细、订单归属和审核流转，走正式团队安排成本表族。
- 当前系统不再提供按日期库存、锁房、占房、释放库存的功能。

如果后续重新建设酒店库存能力，需要重新调研甲方业务场景后建模，不能恢复旧自控房源设计。
